# Day 2 — Polynomial Regression

## Dataset

Ice Cream Selling Data

## Objective

Build a Polynomial Regression model to capture the non-linear relationship between temperature and ice cream sales.

## Libraries Used

* Pandas
* Matplotlib
* Scikit-learn

## Concepts Covered

* PolynomialFeatures
* Model Training
* Prediction
* R² Score
* Degree Comparison

## Conclusion

Polynomial Regression achieved a better fit than Linear Regression by modeling the curved relationship in the data.
