# 📅 Day 10 - Column Transformer

## 📖 Overview

This project demonstrates how to use **ColumnTransformer** from Scikit-learn to apply different preprocessing techniques to different columns of a dataset.

ColumnTransformer helps combine preprocessing steps such as encoding categorical features and scaling numerical features into a single workflow.
