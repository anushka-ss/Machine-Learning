# 🔤 DAY 22 — VECTORIZATION

## CountVectorizer & TF-IDF Vectorizer

Day 22 focuses on **Text Vectorization**, an important step in Natural Language Processing (NLP).

Machine Learning models cannot directly understand raw text.

Vectorization converts text into **numerical representations** that Machine Learning algorithms can process.
