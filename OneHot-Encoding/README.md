# 📅 Day 7 - One-Hot Encoding

## 📖 Overview

This project demonstrates One-Hot Encoding using Scikit-Learn.

One-Hot Encoding converts categorical variables into binary (0 or 1) columns, making them suitable for Machine Learning algorithms without introducing an artificial order between categories.

Sample categorical dataset created for learning One-Hot Encoding.
