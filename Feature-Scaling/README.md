# 📅 Day 4 - Feature Scaling (StandardScaler)

## 📖 Overview

This project demonstrates how Feature Scaling works using StandardScaler from Scikit-Learn.

Feature Scaling is an important preprocessing step in Machine Learning because it brings all numerical features to a common scale.

---

## 📂 Dataset

The dataset contains numerical values that are transformed using StandardScaler.
