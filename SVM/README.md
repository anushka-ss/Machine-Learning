### 🤖 SVM — Binary Classification

---

## 📌 OVERVIEW

In Day 20, I implemented a **Support Vector Machine (SVM)** classification workflow using `SVC` from Scikit-learn.

The project uses a **Loan dataset** to perform binary classification using the `loan_status` target variable.

The workflow includes:

- Data preprocessing
- One-Hot Encoding
- Standard Scaling
- ColumnTransformer
- Pipeline
- Support Vector Classifier
- GridSearchCV
- Hyperparameter Tuning
- Classification Evaluation

# 🎯 OBJECTIVES

The main objectives of this project are:

- Understand Support Vector Machines
