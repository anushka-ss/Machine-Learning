# 📅 Day 9 - Target Encoding

## 📖 Overview

This project demonstrates Target Encoding, a categorical encoding technique used in Machine Learning.

Target Encoding replaces each category with a statistical value (such as the mean) of the target variable for that category.

Sample dataset created for learning Target Encoding.
