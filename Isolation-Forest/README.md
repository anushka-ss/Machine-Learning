# 🌲 DAY 25 — ISOLATION FOREST

## 🔹 Isolation Forest — Anomaly Detection

Implemented **Isolation Forest** for detecting anomalies in a dataset using Machine Learning.

Isolation Forest is an **unsupervised Machine Learning algorithm** commonly used for identifying unusual or abnormal observations in data.

---

## 🎯 Objective

The objective of this project is to understand how **Isolation Forest** can be used for anomaly detection.

The project includes:

- Loading the dataset
- Exploring the dataset
- Applying Isolation Forest
- Detecting anomalies
- Separating normal and anomalous observations
- Understanding anomaly predictions
