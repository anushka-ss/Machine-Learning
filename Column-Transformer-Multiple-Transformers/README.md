# 📅 Day 11 - Column Transformer with Multiple Transformers

## 📖 Overview

This project demonstrates how to use Scikit-learn's **ColumnTransformer** to apply multiple preprocessing techniques to different columns of a dataset simultaneously.

The preprocessing pipeline includes:

- MinMax Scaling for numerical features
- Target Encoding for high-cardinality categorical features
- Ordinal Encoding for ordered categorical features
