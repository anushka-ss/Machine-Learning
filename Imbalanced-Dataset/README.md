# ⚖️ DAY 24 — IMBALANCED DATASET

## 📊 Handling Imbalanced Dataset in Machine Learning

This project focuses on understanding and handling **imbalanced datasets** in Machine Learning.

The project uses a **spam message dataset** where the number of messages belonging to the `ham` and `spam` classes is significantly different.

---

# 🎯 Objective

The main objective of this project is to understand:

- What is an imbalanced dataset?
- Majority and minority classes
- Class imbalance
- Class weighting
- Undersampling
- Oversampling
- RandomUnderSampler
- SMOTE
- Imbalanced-learn
- Machine Learning pipelines

---
