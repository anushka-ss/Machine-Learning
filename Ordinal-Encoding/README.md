# 📅 Day 8 - Ordinal Encoding

## 📖 Overview

This project demonstrates Ordinal Encoding using Scikit-Learn.

Ordinal Encoding converts categorical values into ordered numerical values while preserving the natural ranking of the categories.

Sample categorical dataset created for learning Ordinal Encoding.
