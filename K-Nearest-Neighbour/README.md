# 📍 DAY 19 — K NEAREST NEIGHBOUR (KNN)

### 🤖 K-Nearest Neighbour Classification in Machine Learning

---

## 📌 OVERVIEW

In Day 19, I implemented the **K-Nearest Neighbour (KNN)** algorithm for a classification problem using the **Diabetes dataset**.

This project focuses on understanding how KNN works, why feature scaling is important for distance-based algorithms, and how **GridSearchCV** can be used to tune KNN hyperparameters.

---

# 🎯 OBJECTIVES

The main objectives of this project are:

- Understand the K-Nearest Neighbour algorithm
- Perform data loading and exploration
- Separate features and target variable
- Split the dataset into training and testing sets
- Apply feature scaling using `RobustScaler`
- Build a Machine Learning pipeline
- Perform hyperparameter tuning using `GridSearchCV`
- Compare different values of `n_neighbors`
- Compare different distance metrics
- Evaluate the final model using classification metrics
